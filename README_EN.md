# Catpaq (WinUI 3)

> [!WARNING]
> This is an unofficial third-party WinUI 3 implementation of catpaq, a personal learning project based on the original catpaq project.
>
> The code is primarily generated with the assistance of DeepSeek, based on the C++ GUI implementation of catpaq, built with C# and WinUI 3, adapted to the Windows 11 style.

## Overview

Catpaq is an archive management tool based on the **ZPAQ** format. This repository is a third-party WinUI 3 implementation: written in C#, with the UI referencing the sidebar and browsing experience of Files (the Windows 11 file explorer), and using the zpaqfranz program as the compression/extraction engine.

> **Original project**: <https://github.com/fcorbelli/catpaq> (Lazarus/Pascal implementation)

## Features

- **Browse archives**: explore the internal structure of `.zpaq` files directly in an explorer-style UI, no need to extract first
- **Create archives**: compression levels, multipart volumes, chunking, AES / Franzen encryption, and more
- **Extract all**: extract the whole archive or only selected entries
- **This PC / Quick access**: Files-style sidebar with local drives and pinned locations
- **File association**: one-click association of `.zpaq` to Catpaq, double-click to open (removable at any time)
- **Multilingual**: built-in language support, auto-follows the system language, switchable in Settings
- **Windows 11 style UI**: Mica background, navigation view, adaptive theme

## Languages

Fully translated languages: Simplified Chinese, English, Italian, Russian, Dutch, German, French, Spanish, Portuguese (Brazil), Japanese, Korean.

Other languages can be selected in Settings or auto-detected from the system, but the UI falls back to English for now.

## Requirements

- Windows 10 1809+ (Windows 11 recommended)
- [.NET SDK](https://dotnet.microsoft.com/) (this project uses the `net10.0-windows10.0.26100.0` preview)
- [Windows App SDK](https://learn.microsoft.com/windows/apps/windows-app-sdk/) 2.3.1

## Build

```bash
# Build (x64)
dotnet build -c Release -p:Platform=x64

# Publish (self-contained, no Windows App Runtime installation required)
dotnet publish -c Release -p:Platform=x64
```

The published output is located at `bin\x64\Release\net10.0-windows10.0.26100.0\win-x64\publish\` — copy it anywhere and run.
